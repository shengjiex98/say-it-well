# Privacy policy

Say It Well is a skills-only plugin. It contains instructions and reference text
for coding agents. It does not include executable code, an MCP server, analytics,
authentication, or network requests.

The plugin itself does not collect, store, transmit, or sell personal data. Your
coding agent and the service that provides it may process prompts, repository
content, and responses under that service's own privacy policy and settings.

Report a privacy concern through the project's
[GitHub issue tracker](https://github.com/shengjiex98/say-it-well/issues).

Last updated: August 20, 2026.
